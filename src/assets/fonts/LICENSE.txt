These static weights are used only for server-side image generation (next/og
`ImageResponse` / satori and the `scripts/generate-brand-assets.ts` script,
which cannot load woff2 or variable fonts). The app's on-screen typography is
loaded separately via `next/font/google` in `src/app/layout.tsx`.

- Manrope-ExtraBold-LatinExt.woff (weight 800, latin-ext subset)
  Copyright 2019 The Manrope Project Authors
  https://github.com/sharanda/manrope
  Source: @fontsource/manrope (files/manrope-latin-ext-800-normal.woff)
  Used only as a glyph fallback in scripts/generate-brand-assets.ts: Google
  Fonts splits Manrope's Indian Rupee sign (₹, U+20B9) into the "latin-ext"
  unicode range, so it is absent from the plain "latin" subset above. The
  script draws from this file only for characters missing from
  Manrope-ExtraBold.woff, so the rupee sign in the OG image still renders in
  Manrope at the correct weight instead of falling back to a missing-glyph
  box.
